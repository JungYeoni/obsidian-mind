# Dump Archive

`/om-dump` saves the exact text it was given here, before classifying or routing any of it. AI extraction is lossy — this folder exists so a later session can check whether a routed note actually says what the original said.

Not a staging area — nothing here is meant to be processed further or deleted. Files are named `YYYY-MM-DD HHmm.md`. Every note `/om-dump` creates or updates from a given dump carries a `source:` field pointing back to the matching file here.
